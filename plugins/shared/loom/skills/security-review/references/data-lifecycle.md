# Data Lifecycle

- Trace sensitive fields through storage, logs, exports, error handling, and backups. Compare policy with the narrowest representations at each boundary.
- Check that cache keys, persisted records, and background work preserve ownership metadata. Review when retention or deletion reaches secondary stores and derived copies.
- Distinguish irreversible deletion from soft deletion, archiving, and deferred cleanup. Capture unknown provider retention guarantees as gaps.
- Cite file paths and field names rather than secret values or personal records. Use synthetic identifiers in the report.
