# Spacing Tokens

Use when adding or reviewing spacing, density, padding, gaps, and rhythm.

## Rules

- Prefer a 4px rhythm or the existing design system's spacing scale.
- Keep spacing semantic: page, section, panel, field, list item, toolbar, table cell, modal, drawer.
- Operational tools should use dense but readable spacing. Marketing pages may use more generous section spacing.
- Avoid magic numbers and inconsistent gaps that make the UI look assembled from unrelated pieces.

## Evidence

TaskResult evidence should identify the spacing system reused or introduced, especially for new UI foundations.
