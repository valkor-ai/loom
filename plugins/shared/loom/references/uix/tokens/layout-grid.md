# Layout Grid Tokens

Use when adding or reviewing page shell, grid, responsive behavior, and fixed-format UI elements.

## Rules

- Choose layout by product scenario: app shell for work tools, docs shell for documentation, narrative sections for marketing, scene-first layout for 3D.
- Define stable dimensions for toolbars, tables, boards, tiles, modals, drawers, and fixed-format controls so dynamic content does not shift the layout.
- For desktop operational tools, prefer a persistent shell plus content region over isolated full-page cards.
- For mobile, collapse navigation predictably and avoid shrinking desktop multi-column layouts into unreadable views.

## Breakpoints

Use existing breakpoints when present. For new systems, define named mobile, tablet, desktop, and wide breakpoints instead of scattering media queries.
