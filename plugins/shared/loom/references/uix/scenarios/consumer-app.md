# Consumer App UIX

Use for customer-facing web or app experiences outside specialized finance, docs, marketing, or developer tools.

## Baseline

- Optimize for task clarity, onboarding, discoverability, and forgiving recovery.
- Use familiar navigation for the platform, clear hierarchy, and progressive disclosure.
- Avoid internal implementation language and avoid showing admin-only or delivery-only details.

## Required Patterns

- Primary actions should be reachable, named by user outcome, and paired with clear feedback.
- Empty states should explain value and next step.
- Account, settings, profile, checkout, booking, or content workflows need loading, validation, success, and error states.
