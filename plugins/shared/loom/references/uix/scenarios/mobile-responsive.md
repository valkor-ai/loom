# Mobile Responsive UIX

Use for responsive web, PWA, and webviews that must work on narrow and wide viewports.

## Baseline

- Design mobile layout as a first-class surface, not a squeezed desktop page.
- Use a single-column flow for narrow screens, larger touch targets, predictable sticky regions, and horizontal overflow only when data tables require it.
- Keep important actions visible without relying on hover.

## Required Patterns

- Check at least one narrow viewport and one desktop/tablet viewport when the task changes responsive UI.
- Tables need mobile overflow, condensed columns, or drill-down behavior.
- Modals should become sheets or full-screen flows when content is too dense for narrow screens.
