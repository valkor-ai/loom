# Data Console UIX

Use for monitoring, analytics, audit, logs, reporting, research, operations dashboards, and data-heavy admin screens.

## Baseline

- Prioritize exact values, comparison, filtering, freshness, and trustworthy state over decoration.
- Use tables for lookup/audit/export, charts for trend or distribution, and summary panels only when they guide the next action.
- Show data source, refresh time, stale/partial data warnings, and empty/error states when relevant.

## Required Patterns

- Filters show applied state and have clear reset.
- Dense labels, numbers, units, dates, and currency should align and wrap predictably.
- Color must not be the only carrier of meaning; pair it with labels, icons, patterns, or text.
- Charts need axes, units, legends or direct labels, keyboard/touch alternatives when interactive, and text summaries when important.
