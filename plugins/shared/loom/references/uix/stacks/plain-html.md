# Plain HTML UIX Stack

Use for static HTML, server-rendered templates, lightweight JavaScript, Tailwind-only pages, and framework-free UI.

## Rules

- Use semantic HTML first: landmarks, headings, labels, buttons, links, tables, forms, and lists.
- Keep CSS tokens and component classes small and reusable.
- Avoid inline styles and scattered arbitrary values for repeated roles.
- Progressive enhancement should leave core content and form behavior usable without complex JavaScript when possible.
- Keyboard focus, mobile viewport, and reduced-motion behavior still apply.
